# Whisper Hallucination Interpretability

Research project on when Whisper writes words that were never spoken, why it happens inside the model, and whether a model-level fix can reduce it without deleting real speech.

- Proposal: [extraCreditProposal.md](extraCreditProposal.md) (PDF: [extraCreditProposal.pdf](extraCreditProposal.pdf))
- Rebuild the PDF: `python buildPdf.py` (needs `markdown-it-py` and Google Chrome)

Status: proposal stage. No experiments have been run yet.
